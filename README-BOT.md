# Настройка Telegram Бота и Mini App (VERTEX Ткани)

Этот бот объединяет ваш сайт, каталог тканей и базу данных Supabase в единое приложение прямо внутри Telegram.

---

## 1. Как создать бота в Telegram (за 2 минуты)

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте ему команду:
   ```text
   /newbot
   ```
3. Введите название бота (например: `VERTEX Ткани | Каталог`).
4. Введите юзернейм для бота, заканчивающийся на `bot` (например: `vertex_textile_bot` или `megatextile_bot`).
5. **@BotFather** поздравит вас и пришлет длинный **HTTP API TOKEN** вида:
   ```text
   7842918234:AAFt9_EXAMPLE_TOKEN_abc123
   ```
   *Скопируйте этот токен.*

---

## 2. Привязка Mini App в @BotFather (чтобы кнопка была в меню)

1. В чате с **@BotFather** отправьте:
   ```text
   /mybots
   ```
2. Выберите созданного бота.
3. Нажмите **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Отправьте ссылку на ваш сайт:
   ```text
   https://user97455.github.io/-----------/
   ```
5. Введите название кнопки:
   ```text
   🧵 Каталог тканей
   ```
*Готово! Теперь у всех пользователей прямо в чате слева внизу будет кнопка каталога.*

---

## 3. Запуск бота на компьютере или сервере

1. Откройте файл `bot.py` и вставьте ваш токен в строку:
   ```python
   BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
   ```
   *(Или запустите через терминал с переменной окружения):*
   ```bash
   BOT_TOKEN="ВАШ_ТОКЕН" python3 bot.py
   ```

2. Бот сразу запустится и подключится к каталогу!

---

## 4. Как делиться правами администратора

Вы можете передавать права на редактирование каталога коллегам любым из трех способов:

### Способ А: Прямо в чате Telegram бота
Отправьте боту команду:
```text
/add_admin @username_коллеги
```
*После этого коллега сразу получит доступ к редактированию товаров при открытии Mini App.*

### Способ Б: Секретной ссылкой в 1 клик
В админ-панели нажмите кнопку **«Скопировать секретную ссылку»** или отправьте ссылку:
```text
https://user97455.github.io/-----------/?admin_key=vertex_admin_7799
```
*Любой человек, перешедший по ней, сразу становится администратором.*

### Способ В: Через Мастер PIN-код
Любой администратор может войти в панель управления, введя мастер-PIN: `7799`.
*(PIN-код можно изменить в панели управления в любой момент).*
