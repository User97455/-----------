# Подключение общего каталога

1. Создайте бесплатный проект на https://supabase.com/dashboard.
2. Откройте **SQL Editor**, создайте запрос, вставьте содержимое `supabase-setup.sql` и нажмите **Run**.
3. В **Authentication → Users** создайте пользователя с e-mail и паролем, которыми будете входить в админку.
4. В SQL Editor выполните последнюю команду из `supabase-setup.sql`, заменив `YOUR_ADMIN_EMAIL@example.com` на e-mail созданного пользователя. Это выдаёт ему права администратора.
5. В **Project Settings → API** скопируйте **Project URL** и **anon public key**. Вставьте их в начало `app.js` вместо двух значений `PASTE_...`.
6. Задеплойте заново все файлы сайта, включая `app.js`.

`anon public key` безопасно находится в браузере. Никогда не добавляйте в сайт ключ `service_role`.

После этого товары, категории и фон сохраняются в базе Supabase и сразу видны всем посетителям. Вход в админку — по e-mail и паролю пользователя Supabase.
